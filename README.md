# GitHub Actions = бесплатный сторож контура ТСПУ

Зачем: инструменты работают 24/7 без сервера и без дома, и тревога приходит в Telegram.
Юридически чисто — это обычный CI (не прокси, не VPN), правил GitHub не нарушает.

## Что внутри
- `.github/workflows/tspu-guard.yml` — запуск каждые 30 мин (+ вручную кнопкой).
- `scripts/tspu_guard.py` — проверки и алерт в Telegram.

## Что проверяет
1. Срок сертификата домена моста (алерт, если < 7 дней).
2. DNS-делегирование туннеля — что NS отвечает.
3. Сквозной канал: поднимает xray-клиент и проверяет, что выходной IP = ожидаемый exit.

## Как включить (одноразово)
1. Создать (или взять существующий) репозиторий на GitHub, залить эти файлы.
2. Settings → Secrets and variables → Actions → New repository secret, добавить:
   - `TG_TOKEN`   — токен бота для алертов
   - `TG_CHAT`    — id чата/канала для алертов
   - `CLIENT_JSON` — содержимое клиентского конфига xray (снять с моста: /usr/local/etc/xray/client-config.json)
   - `DOMAIN`        — домен моста
   - `EXPECT_EXIT`   — ожидаемый выходной IP
   - `TUNNEL_DOMAIN` — домен DNS-туннеля (необязательно)
3. Actions → tspu-guard → Enable (если спросит) → Run workflow (проверить).

Если какой-то пункт не пройдёт — в Telegram придёт «⚠️ Сторож: проблема» со списком.

## Публичный репозиторий
Публичный репо даёт безлимитные бесплатные минуты Actions (у приватного лимит 2000 мин/мес).
Поэтому в коде НЕ должно быть доменов/IP — все они вынесены в секреты.

## Примечание
Репозиторий публичный (безлимитные бесплатные минуты). Чувствительные значения — только в секретах.
